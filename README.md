
```sh
python -m venv .venv
```
That will create a `.venv` folder.

```sh
source .venv/bin/activate
```
That will activate the `.venv` venv virtual environment.

```sh
pip install -r requirements.txt
```

To run the app:
```sh
python app.py
```
> Press CTRL+C to quit

```sh
deactivate
```
That will deactivate the `.venv` venv virtual environment.
